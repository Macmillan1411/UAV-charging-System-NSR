# Interface management

Maintain the current editable Interface Register, preliminary ICD, and DSM here as they become available.

Suggested filenames:
- `T4_Interface_Register_v1.0_YYYYMMDD.xlsx`
- `T4_Preliminary_ICD_v1.0_YYYYMMDD.docx`
- `T4_Interface_DSM_v1.0_YYYYMMDD.xlsx`

The approved PDR baseline should contain exact reviewed revisions of these artifacts. Record interface IDs, responsible owners, measurable interface requirements and verification tests.
